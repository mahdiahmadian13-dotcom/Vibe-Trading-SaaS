# Contract: سهمیه کوپن (coupons)

## GET /me/quota — سهمیه من (کاربر عادی، JWT)

```json
{
  "plan": "free",
  "backtest_daily": {"have": 1, "used_today": 0},
  "swarm_weekly": {"have": 1, "used_this_week": 0},
  "credit_permanent": {"backtest": 2}
}
```

## قوانین مصرف (FR-014/014a/014b)

1. ثبت بک‌تست (فری): اول `daily` امروز → اگر نبود، `credit_permanent` → اگر هیچ‌کدام نبود: `402` + پیام فارسی «کوپن امروز تمام شد، فردا برمی‌گردد».
2. ثبت سوارم (فری): مشابه با `weekly` (انقضا پایان هفته تهران).
3. پلن پولی: بدون سقف در این فیچر.
4. رد اعتبارسنجی ورودی → اصلاً claim نمی‌شود (تسکی ساخته نمی‌شود).
5. خطای سمت ما (موتور/انجین، تایم‌اوت، خرابی گره) → کوپن/اعتبار همان تسک برمی‌گردد.
6. همه claim/refundها در یک تراکنش اتمیک با `grant_key` یکتا (ضدمسابقه).

## رفتارها (قابل‌تست)

- ۲ ثبت هم‌زمان با ۱ کوپن → دقیقاً یکی موفق، دیگری 402.
- تسک ناموفق سمت ما → `quota` دوباره همان مقدار قبلی را نشان می‌دهد.
- نیمه‌شب تهران → `backtest_daily.have` دوباره ۱ (بدون انباشت).
