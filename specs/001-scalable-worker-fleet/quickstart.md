# Quickstart: ناوگان ورکر مقیاس‌پذیر چندسروره

**Date**: 2026-09-15 | **Spec**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md)

راهنمای راستی‌آزمایی سرتاسری فیچر روی سرور واقعی (ماده I قانون‌نامه). پیش‌نیاز: استک بالا (`docker compose ps`) + لاگین `mahdi` در `http://127.0.0.1:9001/app/index.html`.

## ۱) سهمیه کوپن (US-06، SC-006)

```bash
# کاربر فری: ۲ بک‌تست پشت‌سرهم → اولی 200، دومی از اعتبار جایزه 200، سومی 402 فارسی
curl -s -X POST localhost:9001/api/v1/vibe/backtest -H "Authorization: Bearer $T" -d '{"prompt":"..."}'
curl -s localhost:9001/api/v1/me/quota -H "Authorization: Bearer $T"
```

انتظار: `backtest_daily.have` بعد از نیمه‌شب تهران دوباره ۱؛ تسک ناموفق سمت ما کوپن را برمی‌گرداند.

## ۲) kill سرور وسط اجرا (US-04، SC-003)

1. بک‌تست ثبت کن؛ در پنل ببین روی کدام گره رفت.
2. کانتینرهای همان گره را متوقف کن (`docker stop` روی آن سرور یا kill ایجنت).
3. انتظار: تسک روی گره سالم تمام می‌شود؛ کاربر دقیقاً یک نتیجه می‌گیرد؛ پیام تلگرام مدیر (< ۵ دقیقه) + ثبت در پنل.

## ۳) نصب خودکار روی VPS خام (US-09، SC-012)

1. تب نودها → «سرور جدید» → IP + کاربر + رمز/کلید → «نصب خودکار».
2. نوار پیشرفت مرحله‌به‌مرحله را دنبال کن تا `ready`.
3. انتظار: < ۱۵ دقیقه تا «آماده»؛ بدون هیچ SSH دستی؛ سکرت در هیچ لاگی متن ساده نیست:
   `docker logs gateway | grep -i "ssh_password\|PRIVATE KEY"` → خالی.

## ۴) داشبورد زنده (US-10، SC-013)

تب نودها/داشبورد را با ۱۰ تسک فعال باز کن: نمودارها هر ۵ ثانیه حرکت کنند؛ مرگ یک گره → قرمز + سهم صفر؛ روی موبایل (WebView) بدون به‌هم‌ریختگی.

## ۵) آپدیت مرحله‌ای (US-11، SC-014)

«به‌روزرسانی ناوگان» با ۲ گره و تسک در حال اجرا: هر لحظه حداکثر یک گره در آپدیت؛ هیچ تسکی گم نشود؛ شکست یک گره → rollback + توقف بقیه تا تصمیم مدیر.

## ۶) نقش‌ها (US-12، SC-015)

نقش «فقط‌مشاهده» بساز و وارد شو: هیچ دکمه نصب/حذف دیده نشود؛ فراخوانی مستقیم:
`curl -X POST .../fleet/servers` → `403`.

## ۷) قطعی شبکه خصوصی (US-13، SC-016)

اینترفیس Tailscale گره را پایین بیاور: drain + انتقال تسک + پیام تلگرام؛ بالا بیاور: بازگشت خودکار به چرخه.

## ۸) امنیت شبکه (US-08، SC-008)

```bash
nmap -Pn <PUBLIC_IP> -p 6379,5432,8899   # همه بسته
# و از گره راه‌دور: redis-cli -h <PRIVATE_IP> ping  # OK
```

## ۹) نگه‌داری ۳۰ روزه (SC-011)

فایل بک‌تست ۳۱ روزه پاک شده؛ متریک خلاصه‌اش در DB هست؛ کاربر در صورت تمایل قبلش مطلع شده.
